### 👨‍💻 About Me

I am an undergraduate **BSc Informatics student at the University of South Africa (UNISA)** in Pretoria. I specialize in building practical web applications, exploring systems security, and applying empirical data science to solve real-world civic challenges.

- 🔭 **What I'm building:** Scalable civic tech platforms, network security tools, and interactive data dashboards.
- 💡 **Passion:** Solving everyday South African problems — from healthcare queue optimization to public municipal data transparency.
- 🛡️ **Cybersecurity:** Hands-on Linux defense, socket programming, packet inspection with raw sockets, and CIS server hardening.
- 🏆 **Hackathons:** Multi-time competitor in the DIRISA Student Datathon, Mintek AI Hackathon, UniSA Hackathon, and NASA Space Apps Challenge.
- 💬 **Ask me about:** Python, TypeScript, React, Linux system administration, and econometric GIS analysis.
